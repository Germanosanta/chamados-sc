⚠ Regras do Firestore (se encontrar erro de permissão)

No Firebase Console → Firestore → Rules, configure temporariamente para desenvolvimento: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true; // APENAS para importação — altere depois!
    }
  }
}
